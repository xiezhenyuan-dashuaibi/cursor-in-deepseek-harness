# Agent Note: Floating Cursor CLI chat overlay in dsh web

Status: implemented

English | [中文](2026-08-31-floating-cursor-cli-overlay.zh.md)

## Problem

The dsh web GUI still presented a full DSH composer and conversation history while the intended product is Cursor as the brain. Showing a raw xterm of the interactive Cursor TUI was tried first, but operators need a normal conversation panel that distinguishes what they sent from what the model returned, with a composer that does not pin the transcript, and assistant text as Markdown—not a terminal chrome shell.

## Decision

The web app hides DSH chrome and floats a conversation panel that **maps** the Cursor CLI: a long-lived PTY owns slash menus and other below-prompt option surfaces; chat turns use headless `--print --output-format stream-json` so the overlay fold receives real assistant / thinking / tool_call / result events (not PTY screen harvest). Slash confirmations stay arrow keys + Enter into the PTY.

[`@deepseek-ai/dsh-cursor-agent-gateway`](../../../../packages/cursor/agent-gateway/README.md) registers `/cursor-agent` on `ctx.webServer`. One overlay session key owns the interactive CLI PTY (print/force flags stripped) and spawns a headless stream-json child for each `{op:"prompt"}` (with `--resume` after the first `session_id`); the WebSocket is a replaceable viewer ([CLI outlives the socket](../architecture/2026-09-03-cursor-overlay-cli-outlives-socket.md)). The gateway publishes `{op:"mirror"}` with the CLI **gray input-bar** text and every row **strictly below** that bar for option surfaces only. Chromatic selection paint is not the bar. While a below-prompt picker is open, the home tip or a slash/empty draft locates the bar; option labels never do. Idle model/cwd lines under the bar are dropped so they never look like a picker. Chat transcript frames are headless NDJSON `{op:"event"}` payloads; the PTY is never harvested into assistant text. Busy follow-ups use `{op:"prompt",mode:"queue"}` (FIFO drain on exit) and `{op:"followup_cancel"}` (LIFO pop); `mode:"steer"` kills the active child and starts a resume turn. The host screen buffer uses xterm deferred wrap so full-width Ink menu rows followed by CRLF do not skip a line and leave duplicate slash entries. The below-prompt list floats above the composer as a frosted glass card in terminal order: clicks do not pick a row; a focused card uses the same `{op:"keys"}` channel as the composer and focuses an inner text field so CJK IMEs can compose. A live AskQuestion Ink box uses that same `{op:"mirror"}.below` list and wins over a concurrent slash menu. Headless `--print` fabricates `Questions skipped by the user`; the gateway intercepts that `tool_call`, projects the form onto the glass card (always appending Cursor's freeform Other after a trailing catch-all), stops the skipped child, and turns overlay keys into a real answer prompt (Enter confirms the highlighted option; Other accepts typed or IME text). The Host/Origin fence is `isTrustedApiRequest` from the [connection plugin](../../../../packages/client/connection/README.md).

[`@deepseek-ai/dsh-client-ui-cursor-agent`](../../../../packages/client/ui-cursor-agent/README.md) registers `CursorPanel` into `shell.overlay`. The panel stylesheet hides conversation/sidebar/details and paints `[data-shell-overlay]`. Occupying the `conversation` slot remains forbidden so sibling `inject()` waiters still settle.

The overlay is a rounded gray card with **no title bar**. The Cursor mark drags the card; resize handles stay on the edges. n/s/e/w hits are the outer 4px strip so the transcript and rail scrollbars stay clickable; corners keep 12px. A top-right control shrinks the card to a 52px gray-and-black line sprite at the last sprite position (default bottom-right inset). The chip is a gray disc with a complete black ring around a letter C; the ring translates (it does not spin in place) and the C turns so its gap faces the back of travel; a click with little pointer travel expands the card. Chat sessions stay mounted while minimized. A left session rail is one full-height slab, slightly lighter than the transcript (`--dsw-specific-sidebar-fill`), with a 1px divider. Collapsed it is about 40px (mark pinned at the top, a scrolling strip of session icons with + under the list, plugin control pinned at the bottom); hover or a focused name field stretches the same element to about 228px and reveals truncated names plus compact edit/close icons. The expanded rail can create a session (named, or a `Chat N` default), rename a session in place, and end a chosen session. The plugin control lists overlay cards and standalone overlay fibers by name and id and can hide or unplug them; a click opens that list in the expanded rail, directly above the control, and leaving the list closes it. The list viewport is 3.5 rows; further rows scroll. It does not delete checkout packages ([overlay stack](../architecture/2026-09-07-overlay-stack-and-card-plug.md)). The expanded box, last sprite origin, and minimized flag persist in `localStorage` (`dsh.cursor-overlay.geometry`) across a page reload. The session rail (`dsh.cursor-overlay.rail`) stores ids and labels with this `dsh web` process's boot id from the index meta; a later load in the same process rebinds those keys, and a new process starts at Chat 1. Primary-button pointer down on the Cursor window raises it above the overlay-card desk. The transcript fills the rest of the card: **user = gray**, **assistant = base/white**, thinking/tools as faint one-line summaries when those events arrive, and system/init as short activity rows. A running turn paints **生成中…** at the end of the transcript, not above the composer. The composer stays editable while a turn runs; Shift+Enter inserts a newline; Backspace deletes at the caret; chat Enter sends `{op:"prompt"}`, and busy Enter appends `mode:"queue"` into a multi-item strip in the same bottom dock. Esc / cancel pops the newest entry (`followup_cancel`); send-now steers with kill + resume. Slash / option keystrokes are `{op:"keys"}`; `{op:"mirror"}` paints the bar and the glass card while a picker owns them. Confirm keeps the CLI in charge (arrow keys + Enter into the PTY) and never sends `/model` as chat. Composer copy, cut, and paste are clipboard events ([composer clipboard](2026-09-04-cursor-overlay-composer-clipboard.md)), not PTY Ctrl+C/V. Failed-turn abort banners are status chrome, not a draft or picker; `{op:"status",status:"error"}` / `{op:"error"}` return the bar to local chat ([abort chrome](../bug-fix/2026-09-04-cursor-overlay-error-locks-composer.md)). The dock overlays the bottom of `transcriptHost` only while the scroller is within a short stick threshold (composer and queue float together). Transcript `padding-bottom` keeps the last measured dock height while scrolled up so hiding the queue cannot shrink `scrollHeight` and yank the viewport back. Stick-to-bottom follows `stickRef`; a jump-to-bottom control appears when the latch is clear.

A `settings.onboarding` marker with id `cursor-overlay-skip` skips the DeepSeek API-key dialog. Overlay sessions are Cursor `--resume` ids, not DSH Sessions. The host CLI outlives the viewer socket; see [CLI outlives the socket](../architecture/2026-09-03-cursor-overlay-cli-outlives-socket.md). Structured operator JSONL is owned by agent-gateway; see [overlay conversation JSONL](2026-08-31-cursor-overlay-conversation-jsonl.md).

## Alternatives considered

**Full xterm of the interactive TUI as the product UI.** Rejected — operators need gray/white conversation bands and Markdown, not terminal chrome. The PTY stays host-side for control; the overlay remains a mapping wrapper.

**Headless `--print` plus a static slash catalog that sends `/command` as a prompt.** Rejected — selecting `/model` became a chat message instead of the CLI’s cascading option surface.

**Replace the `conversation` occupant.** That undeclares sibling inject seats and stalls boot.

**Iframe Cursor IDE.** Already rejected for `dsh web`.

## Consequences

`dsh --profile web` shows a title-less Cursor chat card over an empty shell. Operators drag it from the Cursor mark and manage sessions from the width-stretching rail. Operators need `packages/cursor/cli` (or `agentCommand`) and must be logged in for the interactive CLI. Below-prompt option surfaces confirm through the PTY; they do not append user chat turns.

## Testing

Package tests cover interactive argv construction, PTY keys/mirror WebSocket forwarding, headless prompt / resume / queue / steer stream-json forwarding (no PTY harvest), screen-buffer + prompt-mirror extraction (including AskQuestion boxes), headless AskQuestion intercept plus overlay answer `{op:"prompt"}`, structured JSONL, overlay slot registration, gray/white bands on prompt/assistant events, assistant GFM rendering, busy Enter multi-item queue float plus LIFO cancel / FIFO drain, a floating pill composer with Shift+Enter newline / Backspace at the caret / Enter `{op:"prompt"}` / Ctrl+C interrupt / clipboard paste / abort banners that do not lock the bar, and a below-prompt mirror that forwards focused `{op:"keys"}` like the composer, a composer that hides after scroll-up including the queue float, named create / in-place rename / end-session on the width-stretching rail, mark drag, edge resize, viewport clamp, restore of the stored box after reload, minimize to the bottom-right sprite, expand on a click without drag, sprite drag without expand, and viewer reconnect with host snapshot as in [CLI outlives the socket](../architecture/2026-09-03-cursor-overlay-cli-outlives-socket.md).
