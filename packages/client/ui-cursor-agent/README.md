# @deepseek-ai/dsh-client-ui-cursor-agent

English | [中文](README.zh.md)

Floating web overlay that maps the official Cursor CLI into a conversation panel. The browser half registers `CursorPanel` into `shell.overlay` and talks to `/cursor-agent?session=` over a JSON WebSocket. Unexpected close reconnects; `{op:"snapshot"}` rebuilds the fold. Rail close sends `{op:"shutdown"}`. Shift+Enter inserts a newline. Backspace deletes at the caret. Chat Enter sends `{op:"prompt"}` so the host can run headless stream-json; the client fold paints assistant Markdown (`MarkdownText`, streaming until `result` / idle), plus collapsed `thinking` / `tool_call` rows when those events arrive, in event order. Only the trailing assistant row is updated; a later snapshot of the same reply drops the earlier assistant draft so thinking and tools are not painted under the answer. A jammed markdown table and a pretty copy of the same opening replace with the later text instead of concatenating. A jammed draft that opened with a different sentence still yields to the later copy when two or more of its sentences appear there. A complete payload, `result`, or idle clears thinking "running" and marks leftover running tools done. Slash menus, AskQuestion boxes, and other option surfaces still use `{op:"keys"}` plus a frosted-glass `{op:"mirror"}` card above the composer (the same key channel from the input or the focused card; clicks do not pick a row). Failed-turn abort chrome (`Error: [aborted] …`) is a transcript alert, not a composer draft or PTY latch. Composer copy/cut/paste are clipboard events, not PTY Ctrl+C/V; Ctrl+C interrupts only when a turn is running and the composer has no selection. Busy Enter appends `mode:"queue"` into a multi-item float (Esc / cancel pops LIFO; send-now steers). `taskToolCall` rows feed a live **Running N agents…** strip; `shellToolCall` rows prefer `$ command` text. A running turn appends **Generating** copy at the end of the transcript. Token copy from `result.usage` sits lightly above a single rounded composer pill (no Send button). The card has **no title bar**: an empty 1cm top band and the Cursor mark drag the window; the band shows **dsh_mcp 启动中** or **dsh_mcp 已连接** from host `{op:"dsh_mcp"}` (`mcp list-tools dsh` of this overlay CLI); n/s/e/w resize hits the outer 4px strip so the transcript and rail scrollbars stay clickable; corners stay 12px; a top-right control shrinks it to a 52px gray-and-black line sprite (default bottom-right) whose complete ring swims by translation and whose letter C turns its gap to the back of travel; overlay type is 90% of DSH chrome. A left session rail (Cursor mark pinned at the top, a scrolling strip of session icons with + under the list, and a plugin control pinned at the bottom) is one slightly lighter slab that stretches from ~40px to ~228px on hover, while a name field is focused, or while the plugin list is open. The same rail reveals truncated names and compact edit/close icons in the extra width; it can create (named or default), rename in place, and end a session. The plugin control pins a 桌面 row and lists overlay cards, unloaded desktop products, and standalone overlay fibers (`dsh.client` without a card `overlayBody`) by name and id; cards can hide or show and insert or unplug, desktop list rows switch the desktop, and fibers unplug only.; a click opens that list in the expanded rail, directly above the control, and leaving the list closes it. The list viewport is 3.5 rows; further rows scroll. It does not delete checkout packages. The expanded box, last sprite origin, and minimized flag persist in `localStorage` (`dsh.cursor-overlay.geometry`) across a page reload. The session rail persists across a reload only while `dsh.cursor-overlay.rail` carries this `dsh web` process's index meta boot id; a new process starts at Chat 1. Primary-button pointer down on the expanded Cursor window raises it above the overlay-card desk (`ctx.overlayStack`). The minimized sprite uses a fixed `z-index` above that stack so a card click cannot cover it. The transcript fills the card (**user gray**, **assistant white/base**). The composer overlays the bottom of `transcriptHost` only while the scroller is within a short stick threshold; scrolling up hides the composer and the queue float and keeps the last dock `padding-bottom` so transcript `scrollHeight` does not shrink and yank the viewport back, and a jump-to-bottom control appears. While the plugin is loaded, CSS hides the DSH conversation column, sidebar, and details. A `settings.onboarding` marker with id `cursor-overlay-skip` skips the DeepSeek API-key dialog.

The `/client` exports are the plugin body (`apply` / `inject`) and the `cursor-agent` locale key union. Panel components stay package-internal.

## Model Experience

None, as the overlay presents Cursor CLI turns; that CLI owns its own model conversation.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **Hiding DSH chrome is CSS, not a slot replacement** — occupying `conversation` would drop the seats sibling plugins inject into and stall boot.
- **Overlay sessions are not DSH Sessions** — each rail entry is one Cursor CLI `--resume` id; switching the DSH sidebar Session does not change them.
- **Token footer follows `result.usage`** — official stream-json puts `inputTokens` / `outputTokens` / cache fields on the turn `result`; the CLI does not emit incremental usage events during a turn.
- **Option surfaces are extracted from the interactive PTY** — the overlay wraps the below-prompt Ink list, including a live AskQuestion box on the same frosted-glass card (it wins if `/` is also open). Headless `--print` skips AskQuestion; the gateway intercepts that `tool_call` and projects the form onto this card, always appending Cursor's freeform Other, so arrows move, Space toggles a listed option or types on Other, printable keys and IME commits edit Other when it is highlighted, and Enter confirms the highlighted option as a real answer prompt. The composer and a focused glass card share that `{op:"keys"}` channel; the card focuses an inner text field so CJK IMEs can compose there the same way they do in the composer. Exotic menus may still need extractor updates. Chat text comes from headless `stream-json`, not screen harvest.
- **No full Cursor `/jobs` task board** — concurrent `taskToolCall` rows and the running-agents strip approximate the TUI “N tasks” chrome when those events arrive; there is no separate ACP/`cursor/task` surface.
- **Busy follow-up `steer` is kill + resume** — see the agent-gateway limitation.
- **Panel geometry is browser-local** — expanded box, sprite origin, and minimized flag persist in `localStorage` (`dsh.cursor-overlay.geometry`) for this origin. Clearing site data restores the default centered box.
- **Rail Chat N follows this `dsh web` process** — `dsh.cursor-overlay.rail` stores ids and labels with the index meta boot id. A reload of the same process continues the count; a new process starts at Chat 1.
- **Host restart drops overlay CLIs** — reconnect restores a session only while `dsh web` still holds that runtime.
- **dsh_mcp chrome follows `mcp list-tools dsh`** — the host probes the same CLI argv; a `--print` turn that already started without `dsh` keeps an empty catalog until the next spawn. The label is not a substitute for that freeze.
- **Hide and insert writes use `/overlay-card` then `/overlay-card-plug` for cards, and `/overlay-plugins-rail` then `/overlay-plugins` for desktop occupants, shaped occupants, and standalone fibers** — the first `/overlay-card` `apply` does not hot-swap; a list-only handler rejects `instances.setHidden` and `occupants.setInserted`. The Cursor panel then writes through `/overlay-card-plug`. Card hide updates `instances.json`; card unplug sets occupant `disabled` on the live profile patch. Desktop 卸下 / 切换桌面 exclusive-enable or disable `overlay-desktop.body` occupants. The pinned 桌面 row is that occupant, not the board. The board is not a list row. A standalone fiber's 拔出 writes that Loader row's `disabled`; hide is not offered. A shaped occupant's `overlayBody: overlay-shaped.body` lists as `shaped` (隐藏 plus 拔出; host `hidden.json`). The shaped board is unlistable, like the desktop board. Hide is not offered on standalone fibers. `overlay:live` writes `./overlay-plugin-rail-rpc.mjs` so `/overlay-plugins-rail` can mount when this package's cached `apply` still serves a stale `/overlay-plugins`. The panel does not call `overlay:live remove`.
