# @deepseek-ai/dsh-client-ui-cursor-agent

English | [中文](README.zh.md)

Floating web overlay that maps the official Cursor CLI into a conversation panel. The browser half registers `CursorPanel` into `shell.overlay` and talks to `/cursor-agent?session=` over a JSON WebSocket. Unexpected close reconnects; `{op:"snapshot"}` rebuilds the fold. Rail close sends `{op:"shutdown"}`. Shift+Enter inserts a newline. Backspace deletes at the caret. Chat Enter sends `{op:"prompt"}` so the host can run headless stream-json; the client fold paints assistant Markdown (`MarkdownText`, streaming until `result` / idle), plus collapsed `thinking` / `tool_call` rows when those events arrive. Slash menus, AskQuestion boxes, and other option surfaces still use `{op:"keys"}` plus a frosted-glass `{op:"mirror"}` card above the composer (the same key channel from the input or the focused card; clicks do not pick a row). Failed-turn abort chrome (`Error: [aborted] …`) is a transcript alert, not a composer draft or PTY latch. Composer copy/cut/paste are clipboard events, not PTY Ctrl+C/V; Ctrl+C interrupts only when a turn is running and the composer has no selection. Busy Enter appends `mode:"queue"` into a multi-item float (Esc / cancel pops LIFO; send-now steers). `taskToolCall` rows feed a live **Running N agents…** strip; `shellToolCall` rows prefer `$ command` text. A running turn appends **Generating** copy at the end of the transcript. Token copy from `result.usage` sits lightly above a single rounded composer pill (no Send button). The card has **no title bar**: an empty 1cm top band and the Cursor mark drag the window; n/s/e/w resize hits the outer 4px strip so the transcript and rail scrollbars stay clickable; corners stay 12px; a top-right control shrinks it to a 52px gray-and-black line sprite (default bottom-right) whose complete ring swims by translation and whose letter C turns its gap to the back of travel; overlay type is 90% of DSH chrome. A left session rail (Cursor mark pinned at the top, a scrolling strip of session icons with + under the list, and a plugin control pinned at the bottom) is one slightly lighter slab that stretches from ~40px to ~228px on hover, while a name field is focused, or while the plugin list is open. The same rail reveals truncated names and compact edit/close icons in the extra width; it can create (named or default), rename in place, and end a session. The plugin control lists overlay cards by name and unique id and can hide or show them and insert or unplug occupant fibers; a click opens that list in the expanded rail, directly above the control, and leaving the list closes it. The list viewport is 3.5 rows; further rows scroll. It does not delete checkout packages. The expanded box, last sprite origin, and minimized flag persist in `localStorage` (`dsh.cursor-overlay.geometry`) across a page reload, same as the session rail. Primary-button pointer down on the expanded Cursor window raises it above the overlay-card desk (`ctx.overlayStack`). The minimized sprite uses a fixed `z-index` above that stack so a card click cannot cover it. The transcript fills the card (**user gray**, **assistant white/base**). The composer overlays the bottom of `transcriptHost` only while the scroller is within a short stick threshold; scrolling up hides the composer and the queue float and keeps the last dock `padding-bottom` so transcript `scrollHeight` does not shrink and yank the viewport back, and a jump-to-bottom control appears. While the plugin is loaded, CSS hides the DSH conversation column, sidebar, and details. A `settings.onboarding` marker with id `cursor-overlay-skip` skips the DeepSeek API-key dialog.

The `/client` exports are the plugin body (`apply` / `inject`) and the `cursor-agent` locale key union. Panel components stay package-internal.

## Model Experience

None, as the overlay presents Cursor CLI turns; that CLI owns its own model conversation.

#### KV Cache effect

None; this package neither assembles nor sends a provider request.

## Known Limitations and Deferred Work

- **Hiding DSH chrome is CSS, not a slot replacement** — occupying `conversation` would drop the seats sibling plugins inject into and stall boot.
- **Overlay sessions are not DSH Sessions** — each rail entry is one Cursor CLI `--resume` id; switching the DSH sidebar Session does not change them.
- **Token footer follows `result.usage`** — official stream-json puts `inputTokens` / `outputTokens` / cache fields on the turn `result`; the CLI does not emit incremental usage events during a turn.
- **Option surfaces are extracted from the interactive PTY** — the overlay wraps the below-prompt Ink list, including a live AskQuestion box on the same frosted-glass card (it wins if `/` is also open). Headless `--print` skips AskQuestion; the gateway intercepts that `tool_call` and projects the form onto this card, always appending Cursor's freeform Other, so arrows move, Space toggles a listed option or types on Other, printable keys and IME commits edit Other when it is highlighted, and Enter confirms the highlighted option as a real answer prompt. The composer and a focused glass card share that `{op:"keys"}` channel; the card focuses an inner text field so CJK IMEs can compose there the same way they do in the composer. Exotic menus may still need extractor updates. Chat text comes from headless `stream-json`, not screen harvest.
- **No full Cursor `/jobs` task board** — concurrent `taskToolCall` rows and the running-agents strip approximate the TUI “N tasks” chrome when those events arrive; there is no separate ACP/`cursor/task` surface.
- **Busy follow-up `steer` is kill + resume** — see the agent-gateway limitation.
- **Panel geometry is browser-local** — expanded box, sprite origin, and minimized flag persist in `localStorage` (`dsh.cursor-overlay.geometry`) for this origin, same as the session rail. Clearing site data restores the default centered box.
- **Host restart drops overlay CLIs** — reconnect restores a session only while `dsh web` still holds that runtime.
- **Hide and insert writes use `/overlay-card` then `/overlay-card-plug`** — the first `/overlay-card` `apply` does not hot-swap; a list-only handler rejects `instances.setHidden` and `occupants.setInserted`. The Cursor panel then writes through `/overlay-card-plug`. Hide updates `instances.json`; unplug sets occupant `disabled` on the live profile patch. The panel does not call `overlay:live remove`.
