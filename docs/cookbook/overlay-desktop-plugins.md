# Overlay desktop plugins

English | [中文](overlay-desktop-plugins.zh.md)

This page is the documentation-site pointer for the **desktop** overlay frontend form (product name 桌面). Overlay Cursor and other agents load that HOW with `dsh_skill` (`name: dsh-overlay-canvas-plugins`) before writing or live-inserting a desktop page. If `dsh_skill` is missing, read [`.agents/skills/dsh-overlay-canvas-plugins/SKILL.md`](../../.agents/skills/dsh-overlay-canvas-plugins/SKILL.md) from disk and continue. Card-window HOW is skill `dsh-overlay-web-plugins`. Arbitrary-shape floaters have reserved skill `dsh-overlay-shaped-plugins`. Do not follow the card skill for the desktop. Do not hunt a second desktop procedure.

The canonical reusable board is [`ui-overlay-desktop`](../../packages/client/ui-overlay-desktop/README.md) (`overlay-desktop` / `overlay-desktop.body`). A desktop job inserts that package (`pnpm overlay:live insert packages/client/ui-overlay-desktop`; repeat insert is a no-op), then writes a page with `pnpm overlay:new-desktop <name>` and inserts that page for `overlay-desktop.body`. `overlay:live insert` builds `lib/` when `tsdown.config.ts` is present and waits until the npm name is in `window.__DSH_BOOT__`. The plugin rail lists profile yaml; that list is not the boot graph. Confirm `/plugins/<pkg>/client.js` 200 and that filled `空桌面` is gone. When the wait fails, stderr says whether the Loader fiber is missing (`failed` / absent → new npm name and new `--id`) or `active` (client-modules compose miss; do not rename). Declare `dsh.client.overlayBody` on the page package. Optional `dsh.client.panelTitle` is the rail 桌面 label. Dual-face host RPC and the body page share one Loader row. Keep the generated export name `OverlayPageKey`. Unload a page occupant with `pnpm overlay:live remove <id>`: that deletes the live copy and, for an omitted lab occupant, the checkout package plus its inventory and catalog rows. Do not copy the board tree or clone another occupant. After the stub exists, invent look from this product's brief and the generator stub. Do not search, grep, or open another occupant's page frontend as reference, and do not copy the currently painted overlay, unless the user explicitly asked to make something similar to that product ([visual independence](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)). After adding `packages/client/<name>`, run `pnpm install --filter ./packages/client/<name>...` so `react` links.
