# Overlay 桌面插件

[English](overlay-desktop-plugins.md) | 中文

本页是 **桌面** overlay 前端形态（产品名桌面）在文档站点上的指针页。Overlay Cursor 和其他 agent 在编写或现场插入桌面页面之前，用 `dsh_skill`（`name: dsh-overlay-canvas-plugins`）加载该 HOW。若 `dsh_skill` 缺失，从磁盘读取 [`.agents/skills/dsh-overlay-canvas-plugins/SKILL.md`](../../.agents/skills/dsh-overlay-canvas-plugins/SKILL.md) 并继续。卡片窗口 HOW 是 skill `dsh-overlay-web-plugins`。任意形状悬件加载 skill `dsh-overlay-shaped-plugins`；文档站点指针是 [overlay 异形插件](overlay-shaped-plugins.md)。桌面不要走卡片 skill。不要再找第二套桌面规程。

可复用基模的规范位置是 [`ui-overlay-desktop`](../../packages/client/ui-overlay-desktop/README.md)（`overlay-desktop` / `overlay-desktop.body`）。桌面任务插入该包（`pnpm overlay:live insert packages/client/ui-overlay-desktop`；再次插入是空操作），再用 `pnpm overlay:new-desktop <name>` 写出页面并插入 `overlay-desktop.body`。`overlay:live insert` 在有 `tsdown.config.ts` 时构建 `lib/`，并等到 npm 名出现在 `window.__DSH_BOOT__`。插件栏列出的是 profile yaml；那份列表不是启动图。确认 `/plugins/<pkg>/client.js` 返回 200，且填充的「空桌面」已消失。等待失败时，stderr 会说明 Loader fiber 是缺失（`failed` / 不存在 → 新 npm 名和新 `--id`）还是 `active`（client-modules 组合遗漏；不要改名）。页面包声明 `dsh.client.overlayBody`。可选 `dsh.client.panelTitle` 是插件栏桌面行标签。双面宿主 RPC 和窗体页共用一行 Loader。保持生成的导出名 `OverlayPageKey`。卸载页面占用者用 `pnpm overlay:live remove <id>`：会删掉现场副本；对省略名单上的实验占用者，还会删掉 checkout 包以及注册表和目录行。不要复制基模树，也不要克隆另一个占用者。占位出现之后，画面从该产品的任务说明和生成器占位发明。不要搜索、grep 或打开另一个占用者的页面前端作参考，也不要复制当前画着的 overlay，除非用户明确要求做一个与那个产品类似的东西（[画面独立](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)）。新增 `packages/client/<name>` 之后跑 `pnpm install --filter ./packages/client/<name>...`，以便链接 `react`。现场插入为什么走 profile patch，见 [live-path Agent Note](../../.agents/notes/implemented/architecture/2026-09-04-overlay-web-plugin-live-path.md)。启动图等待与插件栏的划分见 [overlay 现场客户端启动图](../../.agents/notes/implemented/architecture/2026-09-11-overlay-live-client-boot-graph.md)。互斥占用见 [overlay 桌面基模](../../.agents/notes/implemented/architecture/2026-09-10-overlay-desktop-host.md)。页面包骨架见 [overlay new desktop](../../.agents/notes/implemented/process/2026-09-10-overlay-new-desktop.md)。三种形态的划分见 [overlay 前端形态 skill](../../.agents/notes/implemented/process/2026-09-05-overlay-frontend-form-skills.md)。Overlay Cursor 的常驻规则：`.cursor/rules/dsh-cursor-in-dsh.mdc`。客户端插件注册表是 [`packages/client/README.md`](../../packages/client/README.md)；每个包的 README 拥有该插件的描述。操作 HOW 仍在 skill。
