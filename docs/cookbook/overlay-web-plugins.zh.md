# Overlay web plugins

[English](overlay-web-plugins.md) | 中文

本页是 **卡片窗口** overlay 前端形态在文档站点上的指针页。Overlay Cursor 和其他 agent 在编写或现场插入卡片窗口页面之前，用 `dsh_skill`（`name: dsh-overlay-web-plugins`）加载该 HOW。任意形状悬件有预留 skill `dsh-overlay-shaped-plugins`。桌面 HOW 是 skill `dsh-overlay-canvas-plugins`；文档站点指针是 [overlay 桌面插件](overlay-desktop-plugins.md)。那些形态不要走卡片 skill。不要再找第二套卡片规程。

可复用卡片的规范位置是 [`ui-float-window`](../../packages/client/ui-float-window/README.md)（`overlay-card` / `overlay-card.body`）。卡片窗口任务插入该包（`pnpm overlay:live insert packages/client/ui-float-window`，可选 `--title` / `--card-id` / `--width` / `--height`；之后再插入同一包会再加一张卡片），再用 `pnpm overlay:new-page <name>` 写出页面并插入 `overlay-card.body`。页面包声明 `dsh.client.overlayBody`。双面宿主 RPC 和窗体页共用一行 Loader，Cursor 侧栏才能隐藏或拔出整张卡。同一窗口再插一个仅宿主包，不会成为该卡的占用者。卸载一扇窗用 `pnpm overlay:live remove overlay-card-<id>`。卸载页面占用者用 `pnpm overlay:live remove <id>`：会删掉现场副本；对省略名单上的实验占用者，还会删掉 checkout 包以及注册表和目录行。不要复制卡片树，也不要克隆另一个占用者。占位出现之后，画面从该产品的任务说明和生成器占位发明。不要搜索、grep 或打开另一个占用者的页面前端作参考，也不要复制当前画着的 overlay，除非用户明确要求做一个与那个产品类似的东西（[画面独立](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)）。新增 `packages/client/<name>` 之后跑 `pnpm install --filter ./packages/client/<name>...`，以便链接 `react`。现场插入为什么走 profile patch，见 [live-path Agent Note](../../.agents/notes/implemented/architecture/2026-09-04-overlay-web-plugin-live-path.md)。`overlay:live` 等待失败时，stderr 会区分 Loader fiber 与 `window.__DSH_BOOT__`（[启动图](../../.agents/notes/implemented/architecture/2026-09-11-overlay-live-client-boot-graph.md)）。隐藏与 Loader `disabled` 见 [overlay 卡片隐藏](../../.agents/notes/implemented/architecture/2026-09-07-overlay-card-hide-and-loader-disabled.md)。顶栏「缩小」把卡片收成边缘标签，见 [边缘标签](../../.agents/notes/implemented/architecture/2026-09-07-overlay-card-edge-tag.md)。可复用卡片的决策见 [overlay-card 容器](../../.agents/notes/implemented/architecture/2026-09-05-overlay-card-container.md)。页面包骨架见 [overlay new page](../../.agents/notes/implemented/process/2026-09-05-overlay-new-page.md)。三种形态的划分见 [overlay 前端形态 skill](../../.agents/notes/implemented/process/2026-09-05-overlay-frontend-form-skills.md)。Overlay Cursor 的常驻规则：`.cursor/rules/dsh-cursor-in-dsh.mdc`。客户端插件注册表是 [`packages/client/README.md`](../../packages/client/README.md)；每个包的 README 拥有该插件的描述。操作 HOW 仍在 skill。
