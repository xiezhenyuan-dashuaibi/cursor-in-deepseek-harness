# Overlay 异形插件

[English](overlay-shaped-plugins.md) | 中文

本页是 **任意形状** overlay 前端形态（精灵、电视形悬件、任何非卡片轮廓）在文档站点上的指针页。Overlay Cursor 和其他 agent 在编写或现场插入异形占用者之前，用 `dsh_skill`（`name: dsh-overlay-shaped-plugins`）加载该 HOW。若 `dsh_skill` 缺失，从磁盘读取 [`.agents/skills/dsh-overlay-shaped-plugins/SKILL.md`](../../.agents/skills/dsh-overlay-shaped-plugins/SKILL.md) 并继续。卡片窗口 HOW 是 skill `dsh-overlay-web-plugins`。桌面（桌面）HOW 是 skill `dsh-overlay-canvas-plugins`；文档站点指针是 [overlay 桌面插件](overlay-desktop-plugins.md)。非卡片轮廓不要走卡片或桌面 skill。不要再找第二套异形规程。

规范的可复用画板是 [`ui-overlay-shaped`](../../packages/client/ui-overlay-shaped/README.md)（`overlay-shaped` / `overlay-shaped.body`）。异形任务先插入该包（`pnpm overlay:live insert packages/client/ui-overlay-shaped`；再次插入是空操作；刷新用 `overlay:live update`），再用 `pnpm overlay:new-shaped <name>` 写出占用者，并插入该占用者到 `overlay-shaped.body`。`overlay:live insert` 在有 `tsdown.config.ts` 时构建 `lib/`，并等到 npm 名出现在 `window.__DSH_BOOT__`。插件栏列的是 profile yaml；那份列表不是启动图。确认 `/plugins/<pkg>/client.js` 200，以及剪影出现在 overlay 层。等待失败时，stderr 会说明 Loader fiber 缺失（`failed` / 不存在 → 新 npm 名和新 `--id`）还是 `active`（client-modules 组合未挂上；不要改名）。占用者包声明 `dsh.client.overlayBody`。可选 `dsh.client.panelTitle` 是轨上 fiber 标签。双面 host RPC 和剪影共用一个 Loader 行。保持生成的导出名 `OverlayShapedKey`。可以同时启用多个占用者。卸载占用者用 `pnpm overlay:live remove <id>`：删除 live 副本，对省略名单实验占用者还会删除 checkout 包及其注册表和目录行。不要复制画板树或克隆另一个占用者。占位出现之后，从本产品的任务说明和生成器占位发明画面。不要搜索、grep 或打开另一个占用者的前端作参考，也不要拷当前画着的 overlay，除非用户明确要求做一个与那个产品类似的东西（[画面独立](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)）。新增 `packages/client/<name>` 之后，运行 `pnpm install --filter ./packages/client/<name>...` 以便链接 `react`。现场插入为什么走 profile patch 写在 [live-path Agent Note](../../.agents/notes/implemented/architecture/2026-09-04-overlay-web-plugin-live-path.md)。启动图等待与轨的区别是 [overlay live client boot graph](../../.agents/notes/implemented/architecture/2026-09-11-overlay-live-client-boot-graph.md)。并存占用是 [overlay 异形宿主](../../.agents/notes/implemented/architecture/2026-09-14-overlay-shaped-host.md)。宿主拖动是 [overlay 异形拖动](../../.agents/notes/implemented/architecture/2026-09-14-overlay-shaped-drag.md)。占用者 `onClick` 是交互契约；宿主 Pointer Capture 在 `SHAPED_CLICK_SLOP`（6px）之后才开始。线格与命中层共用一个内尺寸（主题 `border-box` 会让 `border` 吃掉内容盒）。宿主隐藏见 [overlay 异形隐藏](../../.agents/notes/implemented/architecture/2026-09-14-overlay-shaped-hide.md)。占用者包骨架是 [overlay 异形占用者生成](../../.agents/notes/implemented/process/2026-09-14-overlay-new-shaped.md)。三种形态的划分是 [overlay 前端形态 skill](../../.agents/notes/implemented/process/2026-09-05-overlay-frontend-form-skills.md)。Overlay Cursor 常驻规则：`.cursor/rules/dsh-cursor-in-dsh.mdc`。客户端插件注册表是 [`packages/client/README.md`](../../packages/client/README.md)；每个包 README 拥有该插件的描述。操作 HOW 仍是 skill。
