# Overlay shaped plugins

English | [中文](overlay-shaped-plugins.zh.md)

This page is the documentation-site pointer for the **arbitrary-shape** overlay frontend form (sprite, TV-shaped widget, any non-card outline). Overlay Cursor and other agents load that HOW with `dsh_skill` (`name: dsh-overlay-shaped-plugins`) before writing or live-inserting a shaped occupant. If `dsh_skill` is missing, read [`.agents/skills/dsh-overlay-shaped-plugins/SKILL.md`](../../.agents/skills/dsh-overlay-shaped-plugins/SKILL.md) from disk and continue. Card-window HOW is skill `dsh-overlay-web-plugins`. Desktop (桌面) HOW is skill `dsh-overlay-canvas-plugins`; its documentation-site pointer is [overlay desktop plugins](overlay-desktop-plugins.md). Do not follow the card or desktop skill for a non-card outline. Do not hunt a second shaped procedure.

The canonical reusable board is [`ui-overlay-shaped`](../../packages/client/ui-overlay-shaped/README.md) (`overlay-shaped` / `overlay-shaped.body`). A shaped job inserts that package (`pnpm overlay:live insert packages/client/ui-overlay-shaped`; repeat insert is a no-op; refresh with `overlay:live update`), then writes an occupant with `pnpm overlay:new-shaped <name>` and inserts that occupant for `overlay-shaped.body`. `overlay:live insert` builds `lib/` when `tsdown.config.ts` is present and waits until the npm name is in `window.__DSH_BOOT__`. The plugin rail lists profile yaml; that list is not the boot graph. Confirm `/plugins/<pkg>/client.js` 200 and that the silhouette is on the overlay layer. When the wait fails, stderr says whether the Loader fiber is missing (`failed` / absent → new npm name and new `--id`) or `active` (client-modules compose miss; do not rename). Declare `dsh.client.overlayBody` on the occupant package. Optional `dsh.client.panelTitle` is the rail fiber label. Dual-face host RPC and the silhouette share one Loader row. Keep the generated export name `OverlayShapedKey`. Many occupants stay enabled at once. Unload an occupant with `pnpm overlay:live remove <id>`: that deletes the live copy and, for an omitted lab occupant, the checkout package plus its inventory and catalog rows. Do not copy the board tree or clone another occupant. After the stub exists, invent look from this product's brief and the generator stub. Do not search, grep, or open another occupant's frontend as reference, and do not copy the currently painted overlay, unless the user explicitly asked to make something similar to that product ([visual independence](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)). After adding `packages/client/<name>`, run `pnpm install --filter ./packages/client/<name>...` so `react` links.
