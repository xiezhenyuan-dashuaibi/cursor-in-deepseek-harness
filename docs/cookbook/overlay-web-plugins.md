# Overlay web plugins

English | [中文](overlay-web-plugins.zh.md)

This page is the documentation-site pointer for the **card-window** overlay frontend form. Overlay Cursor and other agents load that HOW with `dsh_skill` (`name: dsh-overlay-web-plugins`) before writing or live-inserting a card-window page. Arbitrary-shape floaters load skill `dsh-overlay-shaped-plugins`; the documentation-site pointer is [overlay shaped plugins](overlay-shaped-plugins.md). Desktop (桌面) HOW is skill `dsh-overlay-canvas-plugins`; its documentation-site pointer is [overlay desktop plugins](overlay-desktop-plugins.md). Do not follow the card skill for those forms. Do not hunt a second card procedure.

The canonical reusable card is [`ui-float-window`](../../packages/client/ui-float-window/README.md) (`overlay-card` / `overlay-card.body`). A card-window job inserts that package (`pnpm overlay:live insert packages/client/ui-float-window`, with optional `--title` / `--card-id` / `--width` / `--height`; a later insert of the same package adds another card), then writes a page with `pnpm overlay:new-page <name>` and inserts that page for `overlay-card.body`. Declare `dsh.client.overlayBody` on the page package. Dual-face host RPC and the body page share one Loader row so the Cursor rail can hide or unplug the whole card. A host-only extra package for the same window is not that card's occupant. Unload one window with `pnpm overlay:live remove overlay-card-<id>`. Unload a page occupant with `pnpm overlay:live remove <id>`: that deletes the live copy and, for an omitted lab occupant, the checkout package plus its inventory and catalog rows. Do not copy the card tree or clone another occupant. After the stub exists, invent look from this product's brief and the generator stub. Do not search, grep, or open another occupant's page frontend as reference, and do not copy the currently painted overlay, unless the user explicitly asked to make something similar to that product ([visual independence](../../.agents/notes/implemented/process/2026-09-12-overlay-occupant-visual-independence.md)). After adding `packages/client/<name>`, run `pnpm install --filter ./packages/client/<name>...` so `react` links. Why live insert uses the profile patch lives in the [live-path Agent Note](../../.agents/notes/implemented/architecture/2026-09-04-overlay-web-plugin-live-path.md). When `overlay:live` wait fails, stderr classifies Loader fiber vs `window.__DSH_BOOT__` ([boot graph](../../.agents/notes/implemented/architecture/2026-09-11-overlay-live-client-boot-graph.md)). Hide vs Loader `disabled` is [overlay card hide](../../.agents/notes/implemented/architecture/2026-09-07-overlay-card-hide-and-loader-disabled.md). Title-bar 缩小 collapses the card into an edge tag ([edge tag](../../.agents/notes/implemented/architecture/2026-09-07-overlay-card-edge-tag.md)). The reusable card decision is [overlay-card container](../../.agents/notes/implemented/architecture/2026-09-05-overlay-card-container.md). The page-package kit is [overlay new page](../../.agents/notes/implemented/process/2026-09-05-overlay-new-page.md). The three-form split is [overlay frontend form skills](../../.agents/notes/implemented/process/2026-09-05-overlay-frontend-form-skills.md). Overlay Cursor standing order: `.cursor/rules/dsh-cursor-in-dsh.mdc`. Client plugin inventory is [`packages/client/README.md`](../../packages/client/README.md); each package README owns that plugin's description. Operational HOW stays the skill.
